# Public Beta Known Limitations

## Product status
XolveManager is currently a Local-First public beta product. It stores business data in the browser using browser storage mechanisms rather than a centralized cloud database.

## Verified limitations
1. Business data is stored locally in the browser and is not automatically synchronized across devices.
2. No backend or cloud database is part of the current application architecture.
3. Local authentication is not equivalent to server-side identity security.
4. Browser storage can be cleared or become unavailable, which can affect access to records.
5. Support channels are not fully configured or verified for public use.
6. Some public legal content is clearly marked as draft or pending review and should not be treated as final legal terms.
7. The inspected public beta is not a production deployment and should not be treated as a hosted production SaaS service.

## Operational guidance
- Users should maintain their own backups.
- Users should not rely on browser storage as their sole copy of important business records.
- Business owners should review the legal/trust center before using the app for production workflows.
- The project owner should confirm a final support contact and legal review before broad public exposure.

## Release caution
This document should be treated as a disclosure list for the public beta release. It should remain available in the launch package and be refreshed when the app transitions beyond beta.
